# uploads/ — referência operacional

Material de referência fornecido pelo operador (Vinícius Souza): screenshots de
sistemas existentes, conceitos rascunhados em ChatGPT, fotogramas de pauta, e
dois HTMLs antigos de painel (`painel-cliente.html`, `painel-fotografo.html`).

**Não faz parte do cânone do Design System.** Estes arquivos não usam
`colors_and_type.css`, podem conter fontes legadas (Inter, Space Grotesk) e
hex codes fora do sistema de tokens. Tratam-se de insumos brutos que
informaram o DS, não de entregáveis.

Para superfícies canônicas, ver:
- [`../index.html`](../index.html) — ponto de entrada do DS
- [`../ui-kit-public.html`](../ui-kit-public.html) — kit público
- [`../ui-kit-account.html`](../ui-kit-account.html) — kit cliente
- [`../ui-kit-admin.html`](../ui-kit-admin.html) — kit admin

Não editar este diretório como se fosse documentação do DS. Quando uma peça
daqui virar definitiva, ela é traduzida para tokens e migrada para a raiz do
DS — não promovida no lugar.
