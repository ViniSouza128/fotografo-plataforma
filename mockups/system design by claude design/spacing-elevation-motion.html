Espaço · Elevação · Motion

A grade de 4 pixels organiza tudo. Os raios de canto seguem uma escala curta com o pill no fim. As sombras são profundas como um banho fixador. O movimento é tátil sem ser fofinho — usa três easings e quatro durações. Cada token aqui resolve para o colors_and_type.css.

03 · Elevação

Sombras de câmara escura.

As sombras desenham a profundidade do palco. --shadow-1 ancora itens estáveis (navbar sticky, chip ativo). --shadow-2 levanta a peça quando o usuário hovera ou abre dropdown. --shadow-3 isola o foco — modal, drawer. --shadow-glow é o anel de foco visível (combinado com o anel de cor de --focus-ring). O --glow-radial é gradient, e existe apenas atrás do hero.

--shadow-xs

Hairline. Linha de baseline em campo de input com erro, dropdown collapsed.

--shadow-1 · = --shadow-sm

Estável. Navbar sticky, chip selecionado, header fixo de tabela.

--shadow-2 · = --shadow-md

Hover. Card hovered, dropdown aberto, popover de tooltip rico.

--shadow-3 · = --shadow-lg

Foco. Modal, drawer, lightbox de foto, painel modal de configurações.

--shadow-xl

Reservada para confirmações destrutivas que ocupam a tela inteira (logout, excluir álbum).

--shadow-glow

Foco visível em elementos interativos. Sempre em conjunto com --focus-ring para acessibilidade.

--shadow-inset

Microluz superior, 4% branca. Aplica-se em cards para sugerir fina lâmina de luz no topo.

--glow-radial · único gradient permitido

04 · Motion

Quatro durações, três easings.

Passe o mouse sobre cada quadro para ver a curva. As durações se hierarquizam pela urgência da ação: feedback imediato é instantâneo; uma transição padrão respira; um modal entra com peso. Em prefers-reduced-motion, tudo cai para 1 ms (ver token de safety em colors_and_type.css).

  1. < 100 msInstantâneo. Hover de link, cor de borda em focus. Sem token — escolha não ter transição.
  2. 120 ms--duration-quick. Feedback tátil (scroll-arrow, chip-press, click-pulse).
  3. 200 ms--duration-base. Padrão. Card hover, dropdown abrir, troca de cor de fundo.
  4. 320 ms--duration-slow. Deliberado. Modal in, drawer in, transition de página suave.
  5. 560 ms--duration-deliberate. Narrativo. Sucesso ao final do checkout, animação de medalha de patrocínio.

05 · Constantes de layout

Larguras e alturas que não devem ser recomputadas.

Públicos têm 1280 — espaço para a foto respirar. Admin estica para 1440 — caber tabela densa. Conteúdo de prosa (auth, legal) usa 720 — nunca largue um termo de uso em 1280. As alturas de chrome (navbar) também são fixas.

06 · Breakpoints

Cinco viewports de referência.

Os tokens existem para servir como referência cruzada — consuma em @media (min-width: 768px) e referencie pelo nome no comentário. Não há equivalência direta por componente; cada superfície decide seu colapso.

O ponto à esquerda de cada card acende quando a viewport ultrapassa aquele breakpoint — uma régua viva do estado atual da janela.

--bp-sm 480 px

Telefone grande. Limite onde o navbar drawer começa a apertar.

--bp-md 768 px

Tablet retrato. Sidebar colapsa para drawer no admin.

--bp-lg 1024 px

Desktop pequeno. Galeria pública mostra 3 colunas.

--bp-xl 1280 px

Desktop padrão. Galeria pública passa a 4 colunas; admin abre todas as colunas de KPI.
