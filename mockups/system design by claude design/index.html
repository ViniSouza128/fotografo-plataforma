O sistema é
escuro. Por escolha.

Uma plataforma fotográfica brasileira com três superfícies — público, cliente, admin — compartilhando uma única paleta obsidian, três tipografias trabalhando juntas e um único acento âncora. Fotografia narra; a tipografia organiza; a interface desaparece.

Read first

Antes de criar qualquer coisa neste sistema, leia README.md (voz, idioma, arquitetura de marca) e SKILL.md (regras do agente: o que fazer, o que nunca fazer, cheat-sheet de tokens). Tudo nesta página resolve para tokens em colors_and_type.css; nunca declare hex inline.
