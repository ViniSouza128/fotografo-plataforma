01 · Containers

Três larguras canônicas, três tokens.

--content-narrow: 720px para prosa e formulários de autenticação. --content-max: 1280px para o público e a área da cliente. --content-wide: 1440px para o admin (mais densidade, mais colunas). Gutters laterais escalam: 48 px desktop · 32 px tablet · 20 px mobile.

02 · Seção · ritmo vertical

Hero · content · CTA · footer — espaços canônicos.

Toda página pública segue o mesmo ritmo: hero 80–96 px de respiração antes do conteúdo, blocos de conteúdo separados por 64 px, CTA final 64 px de margem superior, footer 96 px. Em mobile, todos os 96 viram 64 e os 64 viram 48. Os tokens de espaço são --space-12 / --space-16 / --space-20 / --space-24.

03 · Page header

Breadcrumb · kicker · título · meta · ações.

07 · Form layouts

Single-column como default. Two-column quando os campos são pares semânticos.

Toda formulário começa em single-column label-top (mais legível, menos quebra mobile). Two-column só para pares óbvios (cidade/UF, mês/ano, preço/desconto). Label-inline só em filtros e em formulários muito longos no admin onde o eixo vertical é caro. Fieldset + legend agrupa campos relacionados — sempre com legend mono uppercase.
