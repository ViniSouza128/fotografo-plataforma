/admin/reset

Operações destrutivas com dupla confirmação + frase digitada. Resetar finanças, eventos (preserva fotos já compradas), clientes (mantém apenas admins), carrinhos, configurações para default ou tudo de uma vez. Sempre cria backup automático antes.

⚙ Configurações⚠ Reset

⚠ Zona perigosa

Todas as operações desta tela criam backup automático antes de executar
⚠ Pare e leia. As ações abaixo apagam dados de forma definitiva. Cada uma exige dupla confirmação + digitação de frase de segurança. Em caso de dúvida, faça um backup manual antes.

💰 Resetar finanças

Apaga: pedidos, payment_log, repasses, cupons usados, audit_log financeiro. Mantém: fotos, álbuns, clientes.

Impacto: 28 pedidos · 19 pagamentos · histórico de R$ 4.218 em vendas

🖼 Resetar eventos & fotos

Apaga: álbuns, fotos não compradas (incluindo do disco), pastas, comentários em fotos. Mantém: fotos já vendidas (clientes continuam baixando).

Impacto: 4 álbuns · 1.298 fotos a apagar (3.6 GB) · 87 fotos preservadas para clientes

👥 Resetar clientes

Apaga: contas de cliente, compras, favoritos, comentários, reclamações. Mantém: contas admin/super-admin.

Impacto: 6 contas · todos vínculos sociais

🛒 Resetar carrinhos

Limpa todos os carrinhos ativos (não afeta pedidos pagos).

Impacto: 7 carrinhos · 32 fotos retidas

⚙ Configurações default

Volta tudo (preço, descontos, derivadas, marca d'água, gateways) ao default de fábrica.

☢ Resetar TUDO

Volta o site ao estado pós-instalação. Apaga absolutamente tudo, exceto a conta super-admin atual.

Esta ação é IRREVERSÍVEL após confirmação tripla.
